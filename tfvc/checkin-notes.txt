Git migration from a clean TFVC checkout
----------------------------------------

The tracked `.gitignore` makes a clean checkout ready for migration without
including TFVC metadata, virtual environments, raw checkpoints, or generated
submission ZIPs. On the destination computer:

1. Create/map a TFVC workspace and get the latest $/RL recursively.
2. Confirm `tf status` reports no pending changes.
3. Do not copy `.tf` from another computer. Remove the local `.tf` directory
   before Git migration if the Git repository should contain no TFVC metadata.
4. Run:

     git init
     git add .
     git status --short

5. Confirm that only source, configs, tests, manuscript source, aggregate
   tables/figures, and reproducibility documentation are staged.
6. Create the initial Git commit, add the desired remote, and push according to
   that host's access policy.

The generated submission files `paper/main.pdf`, `paper/arxiv.pdf`, and
`dist/*.zip` are intentionally ignored. Rebuild them with the tracked scripts.

Windows PowerShell migration
----------------------------

Open Developer PowerShell for Visual Studio so `tf.exe` is on PATH. With an
existing TFVC workspace mapping:

  $TfvcPath = "C:\work\RL"
  Set-Location $TfvcPath
  tf get . /recursive
  tf status . /recursive

Confirm there are no pending changes. The tracked `.gitignore` excludes `.tf`,
virtual environments, raw results, checkpoints, and generated packages, so
Git can be initialized directly in the mapped folder:

  git init
  git add .
  git status --short
  git commit -m "Import SegBench-GC from TFVC"
  git branch -M main
  git remote add origin YOUR_GIT_REMOTE
  git push -u origin main

Record the latest TFVC changeset from `tf history` in the Git commit body if
desired. Keeping `.tf` allows the checkout to remain dual TFVC/Git; it is
ignored by Git. After the Git push is verified, a Git-only copy may remove the
specific `.tf` directory with:

  Remove-Item -Recurse -Force .tf

Native Windows validation:

  py -3.10 -m venv .venv
  .\.venv\Scripts\python.exe -m pip install --upgrade pip setuptools wheel
  .\.venv\Scripts\python.exe -m pip install -e ".[dev,benchmarks,analysis]"
  .\.venv\Scripts\python.exe -m pytest
  .\.venv\Scripts\python.exe scripts\analyze_segbench_gc_results.py
  .\.venv\Scripts\python.exe scripts\build_anonymous_supplement.py
  .\.venv\Scripts\python.exe scripts\build_arxiv_source.py

The tracked experiment launchers and paper compile wrapper are Bash scripts.
Use WSL or Git Bash for those launchers. Alternatively, compile directly from
PowerShell by changing into `paper` and invoking a Windows Tectonic binary:

  Push-Location paper
  tectonic main.tex --keep-logs --keep-intermediates
  tectonic arxiv.tex --keep-logs --keep-intermediates
  Pop-Location
